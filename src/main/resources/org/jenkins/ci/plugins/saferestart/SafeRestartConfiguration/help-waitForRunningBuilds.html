When enabled, the Restart Safely links of this plugin hold back new builds, let every running build finish all its stages, and then restart Jenkins. The core safe restart instead pauses Pipeline builds at their next stage boundary and resumes them after the restart.

While waiting, running builds can still start their remaining node steps and the builds they trigger themselves. A build that never finishes, for example one waiting on an input step, holds the restart until you cancel it.

The CLI safe-restart command, the REST endpoint and other plugins are not affected.
